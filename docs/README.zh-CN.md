# 使用 EDAgent

EDAgent 把芯片物理设计的对话、实际工具调用、检查点和验收证据放在同一个工作台。主 Agent 在本地运行，iEDA 在配置好的 Linux 服务器执行。工作台分别报告流程完成情况与版图质量，保留失败尝试、DRC 计数和交付文件哈希。

## 第一次使用

1. 安装 Python 3.11 或更高版本，从项目根目录执行 `python examples/placement_metrics.py`。示例会计算 8 条网的加权 HPWL，期望值为 2145。这个例子用于验证安装和指标计算。
2. 在 Windows 上按 [英文 README](../README.md) 建立虚拟环境并安装固定版本的 npm 依赖，启动本地工作台。模型密钥在自己电脑上配置。
3. 要运行真实后端，需要配置授权的服务器、iEDA 版本和工艺库。检查 [50 个案例的覆盖表](CASE_MATRIX.md)，区分输入材料、布局与全流程能力。
4. 交付时同时看 routed DEF、版图预览、DRC 报告和产物校验结果。研究用抽象 GDS 和估算时序仅覆盖报告注明的范围。
